# Expense Tracker Application

## Introduction
The Expense Tracker is a Python-based desktop application designed to help users manage their daily income and expenses efficiently. The application provides a simple and user-friendly interface to record, view, and analyze financial transactions.

## Objectives
- To track daily income and expenses
- To categorize expenses for better financial analysis
- To store transaction data securely using SQLite
- To display expense summaries using a GUI dashboard

## Features
- Add, edit, and delete transactions
- Category-wise expense management
- User-friendly Tkinter GUI
- SQLite database for persistent storage
- Modular project structure for easy maintenance

## Technologies Used
- Python
- Tkinter (GUI)
- SQLite (Database)
